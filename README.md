# snake-game

## Цель игры
### В версии 1: **набрать как можно больше очков для рекорда**


## Функциональные требования:

- управление осуществляется с помощью стрелок на клавиатуре или кнопок геймпада;

- **поле** для игры может быть **разных размеров**, при этом размер **выбирается заранее**;

- **игровое поле** может **состоять** из разных **безопасных покрытий**, таких как **трава, земля, песок** или **вода**;

- **на игровом поле** также могут размещаться **препятствия**, например, в виде стен, **столкновение** с которыми **завершает игру**;

- ! (игровое поле генерируется автоматически)

- **игровое поле** создаётся и загружается с помощью **JSON-файла**;

- изначальная длина змеи составляет 3 элемента;

- **скорость змеи** постепенно **увеличивается** по ходу игры, например, возрастая **при каждом пятом** собранном **элементе**;

- ! (начальное **расположение змеи** определяется **случайным образом**);

- змея растет засчет поедания еды;

- ! (еда появляется на поле в случайных местах);

- еда может быть разной: вишня, банан, виноград, яблоко. Соответственно, у каждого вида еды свои особенности, например:
    - вишня дает змее вырасти на один элемент;
    - банан - на три элемента;
    - виноград убирает одно из препятствий с поля (навсегда или на какое-то время), если оно есть;
    - яблоко делает границы игрового поля безопасными на какое-то время;

- также, еда или предметы могут быть вредными и, соответственно, обладать свойствами негативными, например:
    - сигарета затуманивает игровое поле и постепенно рассеивается;
    - кожура от банана изменяет направление змеи (после того как змея съела банан с вероятность 50% на поле появится кожура от банана);
    - энергетик увеличивает текущую скорость в два раза на время;
    - бокал вина забирает у змеи один элемент. Важно! Если у змеи не останентся ни одного элемента - конец игры!

- у игры может быть несколько режимов:
    - классический - просто поле с единственным объектом еды. Могут иметься границы игрового поля, столкновение с которыми завершит игру. Также, змейка может пересекать поле с противоположной стороны — выйдя за верхнюю границу, она появляется снизу, и наоборот;
    - с препятствиями и единственным объектом еды;
    - с препятствиями, с различной едой и подставами;

- игра может состоять из уровней. Причем цель у уровней может быть разной, которая прописывается также в JSON-файле;

- рекорд;

- регистрация пользователя;

- мультиплеер
